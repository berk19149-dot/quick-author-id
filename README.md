# QuickAuthorID

QuickAuthorID is a [Valenced](https://valenced.app/) plugin for Discord on Android. It adds a **Copy Author ID** action to the message long-press menu.

## Features

- Adds **Copy Author ID** to the message long-press menu.
- Uses Discord's copy icon.
- Copies the message author's Discord user ID to the clipboard.
- Shows a confirmation toast after copying.

## Download

[Download the latest release](https://github.com/berk19149-dot/quick-author-id/releases/latest)

Open the latest release, find **Assets**, and download the plugin ZIP. Install it through Valenced.

## Requirements

- Android
- Discord with [Valenced](https://valenced.app/) installed
